# Attributions

Quotology is built on other people's work. This file lists every source; the
same list is shown on the Attributions screen inside the app.

## Quote content

| Source | What | Terms |
|---|---|---|
| [QuoteSlate](https://github.com/Musheer360/QuoteSlate) | Bundled general archive | Open dataset. Each quote names its author. |
| [The Mahabharata](https://www.gutenberg.org/ebooks/15474) | 209 bundled maxims, translated by Kisari Mohan Ganguli, 1883–1896 | Public domain |
| [ZenQuotes](https://zenquotes.io/) | Live quotes | Free tier. Credited as *"Inspirational quotes provided by ZenQuotes API"*. |
| [The Quotes Hub](https://thequoteshub.com/) | Live quotes by subject | Free public API |
| [Bhagavad Gita API](https://vedicscriptures.github.io/) | Live verses with chapter, verse and translator | Free public API. The translator is named with every verse. |
| [Quotable](https://api.quotable.kurokeita.dev/) | Live quotes | Community mirror of the Quotable dataset |
| [Stoic Quotes](https://stoic.tekloon.net/) | Live Stoic passages | Free public API |
| [DummyJSON](https://dummyjson.com/) | Live quotes | Free public API |

Quotations are short passages reproduced with their author named.
