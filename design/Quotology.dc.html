1Quotology — three directions, iOS + Android

All three are the same working prototype: eight screens (daily quotes, quote detail, search, library, settings, onboarding, share sheet, lock-screen widget), the reference palette of teal / amber / red / maroon, and Archivo throughout. Tap a card to expand it, save with the star, ••• opens the share sheet, tabs switch screens, Settings reaches the intro and the widget preview. They differ in the quote-detail treatment, the type scale, and how a card opens.

1aStacked — faithful to the reference. Overlapping colour cards, accordion expand (grid-row grow), detail is a full-bleed colour field with the quote set large.

Assumptions

Data is modelled on a public quotes API — _id, content, author, tags[], plus a source label (book / speech / letter) shown under the author. Card colour is assigned by position in the returned set, cycling four hues, so a refresh reshuffles the colours. Collection counts in Library are placeholders. Illustration is left out: the reference's figure is a stock illustration, so the hero uses a large quote mark instead — drop in real artwork and I'll place it.
